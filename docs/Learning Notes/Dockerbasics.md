# Docker

## What is Docker?

Docker is an application that uses containers and images to run everything required for the software such as dependencies. It does this through images and containers. With the *images* carrying all the technologies needed, runtime and instructions for our code. The container uses the image to create one or more containers. So uses the instructions in the images the container can run all the required code.

## Images

Docker images are made with the instructions required to build the code. This will include downloading all the dependencies, runnning the required files and dependencies.

## Docker compose

The docker compose file is used to run multiple containers in one go, saving the time needed to load up and run multiple different images
